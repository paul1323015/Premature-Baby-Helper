巴掌小太陽 (SunBaby) - 早產兒照護小幫手
本應用程式由早產兒亮愷為公益個人開發，免費提供予所有早產兒家庭免費使用。

「巴掌小太陽」是一款專為早產兒家庭設計的照護紀錄與衛教輔助工具。由於早產兒在成長過程中需要特別關注「矯正月齡」與各項細緻的體征紀錄，本軟體旨在提供一個溫暖、乾淨且直覺的介面，陪伴焦慮的爸媽度過最艱難的照顧時光。

💛 開發初衷與接棒聲明
作者本身亦為早產兒，深知早產兒家庭在照護過程中的焦慮與不易。因個人體力與健康精力有限，本專案以公益開源（Open Source）形式釋出。

若未來作者無法繼續維護更新，非常歡迎對公益資訊軟體有熱情、關心早產兒議題的開發者，基於此專案進行維護、修復 Bug 或功能擴充，讓這份愛的初衷能持續傳承下去，繼續守護每一個巴掌仙子。

🌟 核心功能特色
寶寶基本資料與矯正年齡計算：自動根據出生週數與實際生日，精確計算「矯正月齡」，並同步追蹤當前體重。

今日總奶量進度條：直覺顯示每日目標奶量與完成百分比（例如：60 / 180 ml），方便家長掌握餵食進度。

快速紀錄按鈕：提供一鍵「記餵奶」、「記尿布」快捷鍵，簡化新手爸媽的日常紀錄流程。

照護日誌與成長追蹤：整合「今日快照」、「矯正月齡成長曲線」、「照護日誌」與「看診備忘」。

智慧輔助與資料管理：

AI 諮詢：提供即時的照護建議與諮詢模組。

筆記本與備忘：方便紀錄醫囑或特別注意事項。

備份 / 還原與資料管理：保護家長珍貴的照護資料不丟失。

PDF 匯出：可將紀錄一鍵匯出為 PDF，方便回診時提供給醫師參考。

友善介面設計：支援深色/夜間模式，適合半夜起來餵奶時使用而不刺眼。
